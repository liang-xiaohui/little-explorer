打印说明（只看这一屏，打完后基本不用再看屏幕）
1. 按 Ctrl/Cmd + P 打开打印，纸张选 A4，勾选 「背景图形」（否则虚线、彩色和图标可能不显示），可设彩色打印。
2. 排版已按 A4 紧凑填满：地图每页 2 张；小贴纸（图例/动作/条件）连续流自动填满；控制结构大块单独成页。
3. 沿虚线剪下图例贴纸、小动作块、以及各种开口括号结构块（每条 = 顶部色带 + 左侧虚线「作用域」+ 底部「△ 结束」标签），就是实体积木。一个结构块是一条，不用再单独剪「结束」小条。
4. 玩法：空白地图贴图例拼出「探险地图」→ 把结构块（默认用大框）贴在大纸上作程序骨架，在「作用域」留白处贴动作块 / 条件药丸 → 按程序移动角色（手指或棋子）。
5. 网页版（web/index.html）保留，作参考。
6. 变量部件：变量名贴纸手写名字、贴到结构块旁引用；变量面板用铅笔填值，虚拟运行时擦改写。
7. 控制件统一为开口括号风格、可嵌套：循环 / 条件循环（重复 N 次 / 当[条件]时重复）、函数（定义一次，用「调用」贴纸多次调用）、分支链（如果 / 否则如果 / 否则）、逻辑运算符（且/或/非，串接条件药丸）、扩展条件（开关关着 / 左侧有墙）。嵌套时把小框整条贴进大框的作用域留白区即可。对应 Swift 的 for / while / func / if-else / && || !。
