# Little Explorer · 少儿图形化编程套件

让小朋友用「画画」的方式学编程：先在网格地图上贴图例拼出冒险地图，再用图形积木拼出解题「程序」，最后按程序移动角色。全程零文本代码；既有屏幕版（网页），也有可打印的**纸质实体积木版**，少看屏幕也能玩。

## 为什么这么做

把「编程」拆成两件都是画画的事：

- **画地图** = 设计关卡（在网格上贴宝石 / 开关 / 传送门 / 墙 / 终点）
- **画程序** = 写解法（把图形积木按顺序拼起来）

底层是一个网格世界（grid world），与 Swift Playgrounds 的 *Learn to Code* 同构，但把「设计关卡」本身也图形化了，所以小朋友从第一分钟就在「创作」，而不是先学语法。

## 特性

- **地图元素**：角色、宝石、开关、传送门、墙、终点、起点（贴纸式放置，每格一个）
- **图形程序**：动作块 / 循环（重复 N 次）/ 分支（如果 · 否则如果 · 否则，可拼 else-if 链）/ 变量
- **双形态**：在线编辑器（屏幕）+ 可打印纸质套件（实体），两者表达方式一致
- **胜利条件可配置**：收齐宝石 + 拨开所有开关 + 到达终点
- **少屏幕**：打印 kit 后，地图、程序、运行全在纸面上，铅笔即可维护变量

## 快速开始

- **在线**：浏览器打开 `web/index.html` → 点「载入示例」→ 点「运行」，看角色沿程序走动。
- **纸质**：浏览器打开 `print/print-kit.html` → `Ctrl/Cmd + P` → 纸张 **A4**、勾选 **「背景图形」**、**彩色打印** → 沿虚线裁剪，即得实体积木。

## 纸质玩法

1. 空白地图贴图例 → 拼出一张「探险地图」
2. 把小动作块 / 循环框 / 分支卡贴在一张大纸上 → 拼出「图形程序」
3. 按程序一步步移动角色（用手指或棋子）；**变量面板**用铅笔填值，虚拟运行时擦改写
