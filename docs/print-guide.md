# 打印指南：纸质套件（print-kit.html）

`print/print-kit.html` 是一套可打印的实体积木，打印后沿虚线裁剪，即可在桌面上拼装地图与图形程序，基本不用再看屏幕。

## 1. 打印设置（关键）

打开 `print/print-kit.html` 后按 `Ctrl/Cmd + P`：

- 纸张：**A4**
- 勾选 **「背景图形」**（否则虚线、彩色和图标可能不显示）
- 打印模式：**彩色**

## 2. 套件包含什么

| 部件 | 说明 | 数量/页 |
|---|---|---|
| 空白探险地图 | 5×5 格，留白拼场景 | 每页 2 张 |
| 图例贴纸 | 角色/宝石/开关/传送门/墙/终点/起点，彩色，每格≈地图一格 | 每种 12 个 |
| 图例对照条 | 印在贴纸页顶部，认图标用 | 1 条 |
| 程序动作块 | 前进/左转/右转/收集/切换/跳，小积木 | 每种 14 个 |
| 条件贴纸 | 药丸形：前方有宝石/墙/开关开着/脚下是宝石/在传送门上 | 每种 10 个 |
| 循环框架 | 「重复 N 次」大框 + 「结束重复」 | 4 框 + 8 收尾 |
| 分支链卡 | 如果 / 否则如果 / 否则，可拼 else-if 链 | 如果3·否则如果8·否则4 |
| 变量部件 | 变量名贴纸（名+值两填写位）+ 变量值面板 | 12 贴纸 + 6 行面板 |

## 3. 排版原则（A4 紧凑、减少浪费）

- 地图每页固定 2 张（5×5），刚好吃满 A4 高度。
- 图例总览合并进图例贴纸页顶部，省掉独立一页。
- 小贴纸（图例 / 动作 / 条件）连续流式排布，自动填满每一页，类间不留空。
- 控制结构大块（循环框、分支卡）单独成页、单列流满，不与小贴纸混排；每张卡 `page-break-inside:avoid`，不会被裁切。

## 4. 裁剪与拼装

1. 沿**虚线**剪下各部分。
2. 在空白地图上贴图例 → 拼出「探险地图」。
3. 把小动作块 / 循环框 / 分支卡贴在一张大纸上 → 拼出「图形程序」（动作块小、循环/分支框大）。
4. 按程序一步步移动角色（手指或棋子）；分支卡的条件处贴条件药丸；循环框写次数（数字或变量名）。
5. **变量面板**用铅笔填值，虚拟运行时擦改写。

## 5. 想多印某一类

打印对话框里单独选中那一页、改份数即可；或重复打印某一页。
