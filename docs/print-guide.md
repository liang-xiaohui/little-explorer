# 打印指南：纸质套件（print-kit.html）

`print/print-kit.html` 是一套可打印的实体积木，打印后沿虚线裁剪，即可在桌面上拼装地图与图形程序，基本不用再看屏幕。

## 1. 屏幕预览与打印（每页 = 一张 A4）

`print/print-kit.html` 采用「**一页一个 A4**」模型：屏幕上的每一页就是打印后的一张纸，**所见即所得**，不会再被浏览器自动分页切断。

- **翻页**：点顶部 `‹ ›` 按钮，或直接按 **← → 方向键**；状态栏显示「第 X / 11 页 · 标题」。
- **打印本页**：点 `打印本页`，只输出当前这一张 A4。
- **打印全部**：点 `打印全部`，按顺序输出全部 11 张 A4（自动 1:1 分页）。
- 打印对话框里：纸张选 **A4**、勾选 **「背景图形」**（否则虚线、彩色和图标可能不显示）、选 **彩色**。

> 屏幕预览会自动缩放适配窗口；打印时强制按真实 210×297mm 输出，每页内容已按 A4 可用区（约 194×281mm）排版，不会溢出裁剪。

## 2. 套件包含什么

| 部件 | 说明 | 数量/页 |
|---|---|---|
| 空白探险地图 | 5×5 格，留白拼场景 | 2 页 × 每页 2 张（共 4 张） |
| 图例贴纸 | 角色/宝石/开关/传送门/墙/终点/起点，彩色，每格≈地图一格 | 2 页（4+3 元素）；角色/宝石/开关/传送门/终点/起点 ×12，墙 ×24 |
| 图例对照条 | 印在每页图例顶部，认图标用 | 每页 1 条 |
| 程序动作块 | 前进/左转/右转/收集/切换/跳，小积木 | 2 页（3+3 块）× 每种 14 个 |
| 条件贴纸 | 药丸形 7 种 + 逻辑运算符（且/或/非） | 1 页 · 7 种各 12 + 逻辑每种 6 |
| 开口括号结构块 | 顶部色带+左侧虚线作用域+「△ 结束」标签；大框宽 180mm（循环/当/函数/分支），小框宽 148mm（嵌套用） | 见下方明细 |
| 变量部件 | 变量名贴纸（名+值两填写位）+ 变量值面板 | 1 页 · 20 贴纸 + 8 行面板 |

**结构块分布（共 3 页）**：外层大框①——循环×2、当×1、函数×1、如果×1；外层大框②——如果×1、否则如果×3、否则×1；嵌套小框——循环×2、当×1、如果×1、否则如果×1；调用贴纸×8；函数定义卡与分支链用大框，嵌套用小框。

> **结构块尺寸与嵌套规则**：大框宽 180mm（几乎满 A4），小框宽 148mm。大框「作用域」内可用宽 ≈ 167mm ≥ 小框 148mm，所以小框能直接贴进大框、左右各留约 10mm 缩进；小框作用域内可用宽 ≈ 133mm，可放手动作块 / 条件药丸（42 / 28mm），但放不下另一个小框——即**最多 2 层嵌套**，更深的逻辑建议用「函数」拆开。

## 3. 排版原则（每页 = 一张 A4，紧凑不溢出）

- 套件由 11 个独立 A4 页组成，每页内容都按约 194×281mm 可用区排版（实测每页总高 241–269mm，填充率 85–96%），**不会跨页、不会被裁切**。
- 地图每页固定 2 张（5×5），吃满 A4 高度（≈268mm）。
- 图例总览合并进图例贴纸页顶部，省掉独立一页；墙印得更多（×24）以填满第二页图例。
- 小贴纸（图例 / 动作 / 条件）连续流式排布填满一页，类间不留空；数量按「每页放得下」上调（如动作每块 14 个、条件 7 种合并到 1 页）。
- 控制结构大块（开口括号结构块）按「每页 ≤5 个大框」分发到多页，避免单页溢出。

## 4. 裁剪与拼装

1. 沿**虚线**剪下各部分。
2. 在空白地图上贴图例 → 拼出「探险地图」。
3. 把结构块（默认用**大框**）贴在一张大纸上作程序骨架 → 在「作用域」左侧虚线留白处贴动作块 / 条件药丸，拼出「图形程序」。
4. 嵌套时，把**小框**结构块整条贴进大框的「作用域」留白区即可；左侧虚线随层级向右缩进，一眼看清嵌套关系。
5. 分支链（如果 / 否则如果 / 否则）上下依次拼接，条件处贴条件药丸；循环 / 当框写次数或贴条件。
6. 按程序一步步移动角色（手指或棋子）。
7. **变量面板**用铅笔填值，虚拟运行时擦改写。

## 5. 想多印某一类

打印对话框里单独选中那一页、改份数即可；或重复打印某一页。
