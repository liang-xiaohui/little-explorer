# 打印指南：纸质套件（print-kit.html）

`print/print-kit.html` 是一套可打印的实体积木，打印后沿虚线裁剪，即可在桌面上拼装地图与图形程序，基本不用再看屏幕。

## 1. 打印设置（关键）

打开 `print/print-kit.html` 后按 `Ctrl/Cmd + P`：

- 纸张：**A4**
- 勾选 **「背景图形」**（否则虚线、彩色和图标可能不显示）
- 打印模式：**彩色**

## 2. 套件包含什么

| 部件 | 说明 | 数量/页 |
|---|---|---|
| 空白探险地图 | 5×5 格，留白拼场景 | 每页 2 张 |
| 图例贴纸 | 角色/宝石/开关/传送门/墙/终点/起点，彩色，每格≈地图一格 | 每种 12 个 |
| 图例对照条 | 印在贴纸页顶部，认图标用 | 1 条 |
| 程序动作块 | 前进/左转/右转/收集/切换/跳，小积木 | 每种 14 个 |
| 条件贴纸 | 药丸形 7 种 + 逻辑运算符（且/或/非） | 条件每种 10 · 逻辑每种 8 |
| 开口括号结构块 | 顶部色带+左侧虚线作用域+「△ 结束」标签；大框宽 180mm（循环/当/函数/分支），小框宽 148mm（嵌套用） | 见下方明细 |
| 变量部件 | 变量名贴纸（名+值两填写位）+ 变量值面板 | 12 贴纸 + 6 行面板 |

> **结构块尺寸与嵌套规则**：大框宽 180mm（几乎满 A4），小框宽 148mm。大框「作用域」内可用宽 ≈ 167mm ≥ 小框 148mm，所以小框能直接贴进大框、左右各留约 10mm 缩进；小框作用域内可用宽 ≈ 133mm，可放手动作块 / 条件药丸（42 / 28mm），但放不下另一个小框——即**最多 2 层嵌套**，更深的逻辑建议用「函数」拆开。

## 3. 排版原则（A4 紧凑、减少浪费）

- 地图每页固定 2 张（5×5），刚好吃满 A4 高度。
- 图例总览合并进图例贴纸页顶部，省掉独立一页。
- 小贴纸（图例 / 动作 / 条件）连续流式排布，自动填满每一页，类间不留空。
- 控制结构大块（开口括号结构块）单独成页、单列流满，不与小贴纸混排；每个结构块 `page-break-inside:avoid`，不会被裁切。

## 4. 裁剪与拼装

1. 沿**虚线**剪下各部分。
2. 在空白地图上贴图例 → 拼出「探险地图」。
3. 把结构块（默认用**大框**）贴在一张大纸上作程序骨架 → 在「作用域」左侧虚线留白处贴动作块 / 条件药丸，拼出「图形程序」。
4. 嵌套时，把**小框**结构块整条贴进大框的「作用域」留白区即可；左侧虚线随层级向右缩进，一眼看清嵌套关系。
5. 分支链（如果 / 否则如果 / 否则）上下依次拼接，条件处贴条件药丸；循环 / 当框写次数或贴条件。
6. 按程序一步步移动角色（手指或棋子）。
7. **变量面板**用铅笔填值，虚拟运行时擦改写。

## 5. 想多印某一类

打印对话框里单独选中那一页、改份数即可；或重复打印某一页。
