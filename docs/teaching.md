# 教学引导：给家长 / 老师

Little Explorer 不是"教语法"，而是让小朋友在**创作一个冒险**的过程中，自然建立编程思维。下面是一套从易到难、以"调试"为核心的引导思路。

## 1. 适合谁

- 大约 5–10 岁，刚接触"指令 / 顺序 / 重复 / 条件"概念的孩子。
- 不需要识字很多：图标为主，文字是辅助。
- 屏幕版适合先演示，纸质版适合反复摆弄、少看屏幕。

## 2. 四步进阶路径

### 第一步：画地图（空间与叙事）
让小朋友先在空白地图上贴图例，讲一个故事："小人要去拿宝石、踩开关、走到终点。"这步建立**目标感**和**空间对应**（一格=一步）。

### 第二步：顺序程序（指令与顺序）
只给「前进 / 左转 / 右转」几个动作块，让小朋友把地图"走一遍"写成程序。重点体会：**顺序错了，结果就错**。

### 第三步：重复与分支（抽象）
- 当一段动作要重复，引入「重复 N 次」循环框——把"走 4 步"从 4 个块压成 1 个循环。
- 当"前面可能有宝石也可能没有"，引入「如果 · 否则如果 · 否则」分支卡，体会**条件判断**。

### 第四步：变量（状态）
用变量面板记录会变化的东西（比如剩余步数、开关状态）。让小朋友用铅笔在运行时改写，理解"程序在维护一个会变的量"。

## 3. 用"调试"代替"纠错"

孩子拼出的程序经常不对。不要直接给答案，而是：

1. **让他自己演一遍**：用手指当角色，按程序走，看在哪一步"卡住"或"走偏"。
2. **对比正常/异常**：拿一个能跑的版本和跑偏的版本并排，问"这两步哪里不一样？"——这正是最有价值的排查训练。
3. **小步修改**：改一个块、跑一次，观察差别，而不是一次改很多。

## 4. 给家长的提示

- 地图可以让孩子先**自己手画**再贴图例，保留画画的手感。
- 纸质版的好处是"可触摸、可重排"，比屏幕拖动更利于低龄专注。
- 变量先用**铅笔手填**就够了，不必急着加"设变量"程序块。
- 完成后可以把孩子的地图+程序拍照存档，做成"作品集"。

## 5. 可延伸的项目

- 让孩子**自己设计关卡**给家长解（角色互换，极好的表达训练）。
- 引入"函数"概念：把一段命名后反复调用（套件后续可扩展）。
- 把纸质程序"翻译"回屏幕版运行，建立虚实对应。
